# Refined Masks for ReShapeBench and PIE-Bench

Refined masks for [ReShapeBench](https://github.com/mayuelala/FollowYourShape) and [PIE-Bench](https://github.com/cure-lab/PnPInversion) datasets.

## PIE-Bench

`PIE_Bench_Refined_Masks/` contains refined masks for 460 cases: random, change object, add object, change attribute content, change attribute pose, change attribute color and change attribute material. Download the images and prompts from the [original dataset](https://github.com/cure-lab/PnPInversion). Each mask is named after its case ID.

## ReShapeBench

`ReShapeBench_Refined/` contains the original dataset with the refined masks, split into `single_object` and `multi_object`.
